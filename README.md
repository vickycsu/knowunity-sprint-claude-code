# Knowunity voice recall prototype

Mobile iOS prototype of a voice active-recall step inside Knowunity's study plan. The student explains a concept out loud; Knowie replies in text. 390px, dark mode, recall mocked.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

Project rules live in [CLAUDE.md](CLAUDE.md). Design docs, tokens and reference screenshots are mapped there.
